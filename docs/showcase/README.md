# Showcase

Eight example slides, one per Choosewell method, in the Choosewell palette (plum #2B1B3F, coral #F28C6B). They are the source of `docs/images/social-preview.png` and `docs/images/hero.png`, and are not part of the skill.

| Slide | Method |
|---|---|
| 1 | Options framework: long list to short list |
| 2 | Swing weighting and weighted scores |
| 3 | Sensitivity tornado and switching value |
| 4 | Decision tree and value of information |
| 5 | Value for money: net present social value, benefit-cost ratio, optimism bias |
| 6 | Monte Carlo risk analysis |
| 7 | Minimax regret across scenarios |
| 8 | Five Case Model readiness |

Built with [Slidewell](https://github.com/bmc-marshall/slidewell)'s build library. To rebuild, keep `slidewell/` next to `choosewell/` (or set `SLIDEWELL_SCRIPTS` to Slidewell's `slidewell/scripts`) and run `python docs/showcase/build_choosewell_showcase.py`. The figures are invented and cross-checked in the script.

The advert images use slides 1, 3 and 4.
