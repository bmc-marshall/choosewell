# Step 3: Build the long list

Gather every reasonable option before narrowing down, so the choice isn't limited to whatever someone thought of first.

| | |
|---|---|
| Skip if | A complete list already exists (go to Step 4) |
| You'll end up with | A numbered long list in families, plus early exclusions with reasons (workbook Options tab) |
| Next | Step 4 |

## How

- **Generate broadly**: stakeholder suggestions; how comparable organisations solved the same problem (`topics/comparators.md`); structured frameworks such as the Green Book's five kinds of choice (scope, solution, delivery, implementation, funding), which builds options as coherent combinations; and your own thinking. The type-of-choice file in `choices/` has starter lists.
- **Include business as usual**: what happens if nothing changes. It's the benchmark every other option is measured against, not the same as "do nothing", and it's carried to the final comparison even if it fails criteria. What it means depends on the choice: for **where**, the current footprint (no expansion); for a **matching rule**, the current way of choosing (case by case); for a **name**, a plain descriptive name; for **who**, the current supplier or doing it in-house. If it can't be scored on the criteria, describe it in words beside the results rather than ranking it last.
- **Add flexible versions** when the decision is uncertain and hard to reverse: pilot first, phase it, start small and expand, build in a later switch or exit (Step 9.1).
- **Group options into families** (national vs regional; public vs private; manufacturers vs flavour houses). Families make the list readable, often explain the result, and stop one family dominating by sheer numbers.
- **Merge duplicates** before numbering: workshop and stakeholder lists repeat the same idea in different words. Record what was merged.
- **Number every option once** and never renumber.
- **Combinations**: if an option is really two choices combined (model × host), show a small grid rather than listing every pairing.
- **Early exclusions**: rule out anything clearly impossible now (legal impossibility, policy prohibition, outside scope, an existing exclusive arrangement) with one line on why. Showing these heads off "did you consider…?".

## Checklist
- [quick] Business as usual included as the benchmark
- [quick] Options grouped into families and numbered (numbers never change)
- [quick] Early exclusions listed with a one-line reason each
- [standard] Flexible versions considered (pilot, phase, start small, later switch or exit)
- [standard] Comparators or precedents checked for missing options
